Table

Definición

La etiqueta "table" se utiliza para crear una tabla en una página web. Dentro de ella se organizan los datos en filas y columnas.

Sintaxis

    <table>
   contenido de la tabla
</table>

Ejemplo

Uso:

Se usa para mostrar información organizada, horarios, datos.

tr

Definición

se usa para crear una fila dentro de una tabla.

Sintaxis

   <tr>
   contenido de la fila
   </tr>

Ejemplo

Uso:

Se usa para organizar los datos horizontalmente en la tabla.

th

Definición

se utiliza para agrupar el encabezado de una tabla.

Sintaxis

    <th>Encabezado</th>

Ejemplo

Uso:

Se usa para mostrar los títulos de las columnas o filas en la tabla.

thead

Definición

se utiliza para agrupar el contenido del encabezado de una tabla.

Sintaxis

    <thead>
   encabezados
   </thead>

Ejemplo

Uso:

Separar los títulos de los datos, Mejorar la organización y estructura de la tabla.

tbody

Definición

se usa para agrupar el contenido de una tabla, es decir, los datos que se muestran en la tabla.

Sintaxis

    <tbody>
   contenido
   </tbody>

Ejemplo

Uso:

Separar los títulos de los datos, Mejorar la organización y estructura de la tabla.
