<form>

Definición: Crea un formulario interactivo que permite a los usuarios enviar datos al servidor. Contiene controles de entrada como campos de texto, botones, etc.

Sintaxis:

<form action="/enviar" method="POST">
  <input type="text" name="nombre">
  <button type="submit">Enviar</button>
</form>

Uso: Formularios de contacto, registro, login, búsqueda, encuestas.

<label>

Definición: Define una etiqueta descriptiva para un control de formulario. Mejora la accesibilidad y permite hacer clic en la etiqueta para activar el control.

Sintaxis:

<label for="nombre">Nombre:</label>
<input type="text" id="nombre" name="nombre">

<label>
  Email:
  <input type="email" name="email">
</label>

Uso: Etiquetar campos de formulario, mejorar accesibilidad, UX.

<input>

Definición: Crea un campo de entrada interactivo. Es versátil y puede tener diferentes tipos (text, email, password, etc.). Es una etiqueta vacía.

Sintaxis:

<input type="text" name="usuario" placeholder="Tu nombre">
<input type="email" name="correo" required>
<input type="password" name="clave">
<input type="number" name="edad" min="18" max="100">

Uso: Campos de texto, contraseñas, emails, números, fechas, archivos.

<textarea>

Definición: Crea un área de texto multilínea donde los usuarios pueden escribir texto largo. A diferencia de <input>, permite múltiples líneas.

Sintaxis:

<textarea name="mensaje" rows="5" cols="30">
Texto predeterminado...
</textarea>

<textarea name="comentario" placeholder="Escribe tu comentario"></textarea>

Uso: Comentarios, mensajes, descripciones largas, reseñas.

<select>

Definición: Crea una lista desplegable de opciones. El usuario puede seleccionar una o varias opciones del menú.

Sintaxis:

<select name="pais">
  <option value="">Selecciona un país</option>
  <option value="co">Colombia</option>
  <option value="mx">México</option>
  <option value="ar">Argentina</option>
</select>

Uso: Listas de países, categorías, opciones predefinidas.

<option>

Definición: Define una opción individual dentro de un elemento <select>. Cada opción representa un valor que el usuario puede seleccionar.

Sintaxis:

<select name="color">
  <option value="rojo">Rojo</option>
  <option value="azul" selected>Azul</option>
  <option value="verde">Verde</option>
</select>

Uso: Cada elemento seleccionable dentro de un menú desplegable.

<button>

Definición: Crea un botón interactivo. Puede enviar formularios, ejecutar JavaScript o realizar otras acciones.

Sintaxis:

<button type="submit">Enviar</button>
<button type="button" onclick="alert('Hola')">Clic aquí</button>
<button type="reset">Limpiar formulario</button>

Uso: Enviar formularios, ejecutar acciones, navegar, interacciones.

<fieldset>

Definición: Agrupa elementos relacionados dentro de un formulario. Visualmente crea un recuadro alrededor de los controles agrupados.

Sintaxis:

<fieldset>
  <legend>Información Personal</legend>
  <label>Nombre: <input type="text" name="nombre"></label>
  <label>Edad: <input type="number" name="edad"></label>
</fieldset>

Uso: Agrupar campos relacionados, organizar formularios largos.

<legend>

Definición: Define un título o leyenda para un <fieldset>. Aparece en el borde superior del recuadro del fieldset.

Sintaxis:

<fieldset>
  <legend>Datos de Contacto</legend>
  <input type="email" name="email">
  <input type="tel" name="telefono">
</fieldset>

Uso: Títulos de secciones dentro de formularios agrupados.

<input type="text">

Definición: Crea un campo de entrada de texto de una sola línea. Es el tipo de input más básico y común.

Sintaxis:

<input type="text" name="usuario" placeholder="Usuario">
<input type="text" name="nombre" value="Juan" maxlength="50">

Uso: Nombres, apellidos, títulos, cualquier texto corto.

<input type="email">

Definición: Crea un campo para ingresar direcciones de correo electrónico. Valida automáticamente el formato de email.

Sintaxis:

<input type="email" name="correo" required>
<input type="email" name="email" placeholder="ejemplo@correo.com">

Uso: Formularios de registro, contacto, suscripciones.

<input type="password">

Definición: Crea un campo de contraseña donde los caracteres se ocultan automáticamente (se muestran como puntos o asteriscos).

Sintaxis:

<input type="password" name="clave" required>
<input type="password" name="password" minlength="8">

Uso: Formularios de login, registro, cambio de contraseña.

<input type="number">

Definición: Crea un campo numérico con controles para incrementar o decrementar el valor. Solo acepta números.

Sintaxis:

<input type="number" name="edad" min="18" max="100">
<input type="number" name="cantidad" value="1" step="1">

Uso: Edad, cantidad, precio, cualquier valor numérico.

<input type="date">

Definición: Crea un selector de fecha con un calendario desplegable. El formato de fecha varía según la configuración del navegador.

Sintaxis:

<input type="date" name="nacimiento">
<input type="date" name="fecha" min="2024-01-01" max="2026-12-31">

Uso: Fecha de nacimiento, reservas, eventos, plazos.

<input type="radio">

Definición: Crea botones de opción donde solo se puede seleccionar una opción de un grupo. Todos deben tener el mismo atributo name.

Sintaxis:

<input type="radio" name="genero" value="m" id="masculino">
<label for="masculino">Masculino</label>

<input type="radio" name="genero" value="f" id="femenino">
<label for="femenino">Femenino</label>

Uso: Selección única entre varias opciones (género, método de pago).
