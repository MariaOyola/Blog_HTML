<ul>

Definición: Define una lista desordenada (unordered list). Los elementos de la lista se muestran con viñetas o puntos, sin un orden específico.

Sintaxis:

<ul>
  <li>Primer elemento</li>
  <li>Segundo elemento</li>
  <li>Tercer elemento</li>
</ul>

Uso: Listas de características, menús de navegación, listados sin orden de prioridad.

<ol>

Definición: Define una lista ordenada (ordered list). Los elementos se numeran automáticamente, indicando un orden o secuencia.

Sintaxis:

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>

Uso: Instrucciones paso a paso, rankings, procedimientos ordenados, recetas.

<li>

Definición: Define un elemento individual dentro de una lista (list item). Debe estar contenido dentro de <ul> o <ol>.

Sintaxis:

<ul>
  <li>Elemento de lista 1</li>
  <li>Elemento de lista 2</li>
</ul>

<ol>
  <li>Primer elemento numerado</li>
  <li>Segundo elemento numerado</li>
</ol>

Uso: Cada elemento individual dentro de una lista ordenada o desordenada.

<dl>

Definición: Define una lista de descripción (description list). Se usa para mostrar términos y sus definiciones o descripciones.

Sintaxis:

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para crear páginas web</dd>
  
  <dt>CSS</dt>
  <dd>Lenguaje de estilos para dar formato a HTML</dd>
</dl>

Uso: Glosarios, definiciones, metadatos, pares clave-valor.
